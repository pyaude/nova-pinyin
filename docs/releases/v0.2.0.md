NovaPinyin 首个预发布版本，面向 **Ubuntu 24.04 amd64** 的本地拼音输入与桌面兼容验证。

### 功能

- 全拼、基础句子组合、逐段选词与撤销、光标编辑、数字/空格/鼠标选词和候选翻页。
- 自然码、小鹤、微软双拼，常用模糊音和有限拼音纠错。
- SQLite 本地学习，个人词条导出/清空，领域词库导入、启用/禁用和移除。
- 繁体输出、小型表情候选表、中文设置与词库管理器。
- 隐私模式；密码/敏感字段能力提示下停用学习与个人词条。

### 安装

下载安装包和 `SHA256SUMS` 到同一目录，运行：

```bash
sha256sum --check SHA256SUMS
sudo apt install ./novapinyin_0.2.0-1_amd64.deb
```

运行 `im-config` 选择 Fcitx5，注销后重新登录。打开“Fcitx 5 配置”，取消“仅显示当前语言”筛选，添加“NovaPinyin 拼音”。输入 `nihao` 后按 Space 应得到“你好”。单独 Shift 切换中英文；Enter 提交组合原文。双拼、词库和隐私设置位于“NovaPinyin 词库管理”。

首次安装依赖可能需要联网，输入本身离线。详细步骤和恢复方法见 [安装说明](https://github.com/pyaude/nova-pinyin/blob/v0.2.0/docs/install.md)。卸载命令为 `sudo apt remove novapinyin`，个人数据保留；可通过 `im-config` 恢复原来的输入框架。

### 验证范围与限制

本地验证包含 23 项核心测试、Fcitx5 事件集成测试、真实 GTK3/Qt5 文本框提交、管理器设置/词库操作和安装卸载重装。GitHub Ubuntu 24.04 CI 已通过常规测试及 AddressSanitizer/UndefinedBehaviorSanitizer（启用泄漏检查）。发布流程还会安装生成的包并复核 GTK3/Qt5 与管理器，全部通过后才发布。

本版本为 **Pre-release**。GNOME 原生 Wayland、桌面搜索框、多屏与缩放、Firefox Snap、Chromium/Electron、LibreOffice、GTK4/Qt6 尚待目标环境验证；本包仅面向 Ubuntu 24.04 amd64，其他发行版本和架构需独立构建验证。领域词库仅提供小型示例；纠错与表情候选范围有限。AI、云服务、同步和项目补全未包含在本版本中。

NovaPinyin **v1.0.0 正式版**，分别提供 **Ubuntu 20.04 amd64（X11）** 与 **Ubuntu 24.04 amd64** 安装包。请根据系统版本下载，不能混用。

### 选择安装包

| 系统 | Release 文件 | 运行库与首次启用 |
| --- | --- | --- |
| Ubuntu 20.04 amd64 | `novapinyin_1.0.0-1.ubuntu20.04.1_amd64.deb` | 自带专用 Fcitx5/LibIME；安装后注销重登录或重启一次，自动完成设置 |
| Ubuntu 24.04 amd64 | `novapinyin_1.0.0-1.ubuntu24.04.1_amd64.deb` | 使用系统 Fcitx5/LibIME；im-config 选择 Fcitx5，重登录后在 Fcitx 5 配置添加 NovaPinyin |

下载所需 `.deb` 和 `SHA256SUMS` 到同一目录，运行 `sha256sum --ignore-missing --check SHA256SUMS`，通过后安装。Ubuntu 20.04 示例：

```bash
sudo apt install ./novapinyin_1.0.0-1.ubuntu20.04.1_amd64.deb
```

安装后注销重登录或重启一次，用 Ctrl+Space 切换，输入 `nihao` 并按空格选词。Ubuntu 20.04 自动备份原输入法选择、修正 GTK/Qt/XIM 环境并启动框架，之后尊重用户自行切换的选择；手工会话配置保留。卸载恢复尚未改动的受管选择并保留个人数据。Ubuntu 24.04 的首次启用需按上表设置。

### 本版功能

- 全拼、句子组合、自然码/小鹤/微软双拼、模糊音、纠错、繁体、常用 emoji 与本地学习。
- 统一“NovaPinyin设置”入口，提供双拼方案、输入选项、词库和项目管理。
- 横向拼音候选、更宽间距、浅色/深色主题和蓝底白字高亮，修复旧 Focal 包选中词白底白字的问题；↓ 下一页、↑ 上一页，保留 PageDown/PageUp。
- 可离线安装 Rime 常用词精选（20,000 条）、雾凇社区补充词（162 条）；固定来源、许可和原始词库随包保留。
- 可选内存上下文、显式命令/代码补全和用户主动触发的项目索引，默认关闭。本地处理，不上传按键、词条或源码；隐私/敏感模式停用学习和补全。
- 修复首次 Ctrl+Space 激活时的插件加载重入，保留过期候选防护、失焦取消和补全 Enter 消费规则。

### 升级、源码与验证范围

从 v0.3 直接 apt 升级，保留个人词条、选择次数、词库、项目索引和设置，数据库继续使用 schema 2。升级后重新登录以加载新插件。普通卸载保留用户数据。v0.2 的 schema 1 自动迁移，回退到 v0.2 需要旧数据库备份。

Ubuntu 20.04 另附 `novapinyin_1.0.0-1.ubuntu20.04.1_sources.tar.gz`，包含匹配项目源码、专用运行库源码、模型/词库源数据和许可；Release 的 SHA256SUMS 同时覆盖这份归档。20.04 使用自己的 GCC 10、glibc 2.31 构建，不替换系统 glibc/libstdc++。24.04 使用发行版库构建，两包均由目标系统解析真实库依赖。

发布流程要求两套系统的常规测试、ASan/UBSan（含泄漏检测）、安装后 GTK3/Qt5 中文及补全输入、管理器和候选渲染检查通过；20.04 另验证新用户自动登录、Ctrl+Space、备份及实际卸载恢复。实际记录见 [验证文档](https://github.com/pyaude/nova-pinyin/blob/v1.0.0/docs/validation.md)。

20.04 包关闭原生 Wayland 支持。完整 GNOME/Wayland、多屏缩放、微信 Linux、Edge、LibreOffice、Snap/Flatpak、GTK4/Qt6 等组合尚未完成本轮实际桌面验收；正式版不代表这些组合均已验证。Ubuntu 22.04、26.04、arm64 未提供本次验证包。

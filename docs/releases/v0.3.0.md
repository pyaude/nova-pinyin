NovaPinyin v0.3.0 预发布：新增可控上下文与开发者输入，面向 **Ubuntu 24.04 amd64** 试用验证。v0.2 的全拼、双拼、词库、繁体与本地学习继续保留。

### 新功能

- **内存上下文排序**：默认关闭，仅保留当前输入上下文最近 128 个 Unicode 字符，不保存周围文本；同一次组合中的可见候选不随客户端上下文变化重排。
- **显式命令/代码补全**：默认关闭，启用后按 `Ctrl+Alt+Space` 进入。模式内 Space 输入空格，↑↓ 选择，Tab/Enter 提交文字，Esc 或失焦取消。支持 `git che` → `git checkout` / `git cherry-pick`、`cmake ta` → CMake 名称。
- **项目标识符索引**：用户选择源码目录并主动索引，支持后台索引、重新索引、移除与活动项目选择。遵循 Git 忽略规则及 `.novapinyinignore`，排除凭证、隐藏文件、符号链接、二进制和超大文件。不执行项目代码、不自动读取编辑器项目。
- **可覆盖应用提示**：默认关闭，可配置 `code=editor;kitty=terminal`；仅影响类别提示和标点策略，不自动进入补全或切换中英文。

隐私模式及密码/敏感提示下停用上下文、个人词条和开发者补全。补全不写入学习历史，索引不保存源码，个人词条导出不包含项目索引。

### 安装与升级

下载安装包与 `SHA256SUMS` 到同一目录：

```bash
sha256sum --check SHA256SUMS
sudo apt install ./novapinyin_0.3.0-1_amd64.deb
```

首次安装后运行 `im-config` 选择 Fcitx5、注销重登录，在“Fcitx 5 配置”中添加 NovaPinyin 拼音。新功能在“NovaPinyin 词库管理”中手动开启。

从 v0.2 升级前建议关闭 Fcitx5 并备份个人数据目录。安装后通过菜单重新启动 Fcitx5 或注销重登录，以加载新插件。数据库自动迁移，已有个人词条和领域词库保留；v0.2 不读取迁移后的 schema 2，回退需要升级前备份或新数据目录。卸载保留个人数据；清空学习数据同时删除项目索引，安装的领域词库保留。

### 验证与限制

本地 Ubuntu 24.04 Docker 中 35 项 CTest 及独立 AddressSanitizer/UndefinedBehaviorSanitizer（含泄漏检测）通过，覆盖核心输入、上下文、补全、索引排除规则、数据库升级与焦点/隐私安全；索引测试包含 14 个 Python 场景。GTK3/Qt5 文本框验证普通中文及显式补全提交，管理器验证后台项目索引与选择。已修复上下文评分临时节点寿命问题及普通学习刷新取消补全的问题。发布流程再次构建、进行独立内存检查、安装并执行图形验证，全部通过后才发布；对应源码的远程构建 CI 与标签发布流程需分别确认。

本版本仍为 **Pre-release**。GNOME 原生 Wayland、桌面搜索框、多屏/缩放、Snap/Electron/LibreOffice、GTK4/Qt6 与其他 Ubuntu 版本/架构尚待实际目标环境验证。索引为有界的源码标识符提取，不提供完整语义补全或文件监听；上下文只是有限提示，不保证每次输入改善排序。AI、云服务与自动项目发现未包含。

补全选择的 Enter 只提交文字；随后再次按 Enter 会交给应用，终端可能执行已提交的文字。输入法自身不执行命令。桌面占用默认触发键时，可在设置中更换 `DeveloperKey`。

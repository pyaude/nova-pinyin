# v0.3 上下文与开发者输入

所有新能力默认关闭，可在“NovaPinyin 词库管理”或 Fcitx5 原生输入法设置中开启。

## 内存上下文排序

启用“内存上下文排序”后，组合开始时优先使用客户端提供的光标前文本。只保留最近 128 个 Unicode 字符；客户端未提供时，使用当前输入上下文中本引擎刚提交的有限文字作为弱提示。客户端文本超过 64 KiB、读音组合期间变化或有非空选区时不扩展采集。

使用现有 LibIME 静态语言模型，对前 20 个候选计算有界的上下文分数。不引入模型下载、不生成额外候选，不改变读音或消费范围。已显示的候选在同一次组合中不随客户端上下文变化而重新排序；正常按键编辑仍会生成新的修订号与列表。

这些提示不等于完整文档或编辑器语义，也不承诺每次输入都会改善排序。上下文不写入数据库、日志、词库导出或网络。失焦、重置、配置重载及进入隐私/密码/敏感字段时清除。隐私模式使用基础模型并停用上下文和开发者补全。

## 显式补全模式

启用“显式开发者补全”后，在 NovaPinyin 激活且拼音组合为空时，按 `Ctrl+Alt+Space` 进入补全模式。可在设置中修改 `DeveloperKey`；桌面或应用占用该组合时换用其他快捷键。英文状态下也可显式进入。

| 操作 | 行为 |
| --- | --- |
| Space | 输入前缀中的空格，保持补全模式 |
| 字母、数字与 ASCII 标点 | 编辑前缀，保留大小写，最多 128 字符 |
| 左右/Home/End、Backspace/Delete | 编辑前缀 |
| 上下、PageUp/PageDown | 选择候选、翻页 |
| Tab / Enter / 鼠标选择 | 提交所选候选文字并退出；无候选时提交原文 |
| Esc / 再按触发键 / 失焦 | 取消并退出，不提交前缀 |
| Ctrl/Alt/Super 的其他快捷键 | 取消补全并将快捷键交给应用 |

示例：`git che` 可选择 `git checkout` 或 `git cherry-pick`；`cmake ta` 可选择 `target_link_libraries` 等 CMake 名称。项目候选按标识符大小写前缀匹配，并按源码出现频次排序。

选择候选的 Enter 被输入法消费，**只提交文字**。如果随后再次按 Enter，它会交给应用，终端可能执行已经提交的文字。输入法自身从不调用 Shell 执行补全内容，不读取 Shell 历史或替换编辑器原生补全。

普通学习数据的后台刷新保留正在输入的补全前缀与候选映射。显式清空数据、修改词库、失焦或进入隐私/敏感模式仍会使旧候选失效。

## 用户指定的项目索引

在“项目补全”页添加项目，选择目录并显式索引；索引成功后选择要用于补全的项目并保存。也可运行：

```bash
novapinyin-project 项目名称 /绝对/项目目录
novapinyin-tool projects
novapinyin-tool project-remove 项目名称
```

只提取支持源码中的 ASCII 标识符；支持 C/C++、Python、Rust、Go、JavaScript/TypeScript、Java/Kotlin、Shell 与 CMake。Python 使用词法 token，其他语言使用有限的注释/字符串剔除及标识符规则；不是完整语言服务器。不会从汉字自动推断拼音，不会读取编辑器当前文件、工作目录或自动绑定项目。

索引后台运行，完成后一次事务替换同名数据。失败保留原索引；扫描期间数据被清空或移除时拒绝过期结果。没有文件监听，源码变化后需主动“重新索引”。普通输入事件仅查询已生成的内存索引，不扫描项目文件。

默认排除隐藏文件/目录、常见构建和依赖目录、名字含凭证特征的文件、符号链接、二进制、非 UTF-8 与超大文件；不保留注释和字符串中的单词。索引器不执行项目代码、钩子或 Git fsmonitor。Git 仓库使用 `git check-ignore --no-index` 遵循嵌套 `.gitignore`（包括否定规则）；被忽略的已跟踪文件也排除。非 Git 目录不解释 `.gitignore`，可用 `.novapinyinignore`。

`.novapinyinignore` 位于所选目录根部，只支持 glob 排除规则与注释；不支持 `!` 重新包含规则，例如：

```text
# 排除不希望索引的目录和生成文件
third_party/
*.generated.cpp
internal/**
```

界限：单文件 256 KiB、累计读取 32 MiB、最多尝试读取 2000 个源码文件/遍历 2000 个目录、20 秒扫描预算、单项目 20000 个唯一标识符；最多 10 个项目、合计 100000 个标识符。二进制和非 UTF-8 文件也计入已读取字节，跳过的源码文件也计入尝试次数。单目录枚举最多 10000 项，逐项检查预算；最大目录深度为 32。超出总体限制取消索引，需缩小目录或添加忽略规则。大型文件与不可读文件跳过并报告计数。忽略规则大小也有限制；Git 校验使用剩余扫描预算，读取或提取最后一个文件后超时也取消导入。目录遍历与文件读取均通过所选根目录的文件描述符打开，不跟随遍历期间被替换的目录符号链接。

数据库保存项目名称、用户选择的根路径、标识符与出现频次，不保存源码、文本上下文或补全选择历史。个人词条导出不包含项目索引。移除索引保留源文件；“清空个人学习数据”同时移除所有项目索引，领域词库保留。默认排除规则无法保证识别所有敏感文件，添加项目时应选择希望用于补全的源码目录并补充忽略规则。

## 应用提示

“可覆盖的应用类别提示”默认关闭；启用后使用客户端提供的程序标识，缺失时正常输入仍可用。终端能力标志与常见终端/编辑器标识用于显示提示，并让终端默认使用半角标点，不自动切换中英文或进入补全。关闭时仅保留 v0.2 的终端能力标志处理；隐私/敏感模式不读取应用标识。

可设置 `ApplicationOverrides`，格式为分号分隔的精确程序标识规则：`kitty=terminal;code=editor;firefox=general`。分类值为 `general`、`terminal`、`editor`；这是用户可覆盖的提示，不是桌面识别保证。

## 升级和回退

v0.3 自动将个人数据库从 schema 1 迁移到 schema 2，保留 v0.2 的个人词条与领域词库。升级前建议关闭 Fcitx5 并备份个人数据目录。v0.2 不读取 schema 2；如需回退，应恢复升级前的数据库备份或使用新的用户数据目录。卸载继续保留个人数据。
